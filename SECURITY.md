# Security Policy

## Supported version

Security fixes currently target the latest MipMapPlus release for Minecraft
26.2.

## Private reporting

Please use
[GitHub's private vulnerability reporting](https://github.com/arogorn993-hue/MipMapPlus/security/advisories/new)
for a suspected security issue. Include reproduction steps, impact, and the
affected version. Please allow time for investigation before publishing the
details.

Ordinary crashes, rendering problems, and mod compatibility issues belong in
the public bug report form instead.
