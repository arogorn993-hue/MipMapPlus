# Contributing

Focused issues and pull requests are welcome.

## Commit policy

The commit author must have personally written, reviewed, and understood the
complete change.

Use a single author identity and do not add secondary-author trailers to commit
messages.

## Before submitting

- Keep each change focused and explain any user-visible behavior.
- Run `./gradlew build` (`.\gradlew.bat build` on Windows).
- Describe the Minecraft, Fabric Loader, and optional Sodium versions tested.
- Preserve the MIT license and all applicable third-party notices.
