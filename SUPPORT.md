# Support

## Bugs

Use the
[bug report form](https://github.com/arogorn993-hue/MipMapPlus/issues/new?template=bug-report.yml)
for reproducible crashes, incorrect fallback behavior, visual seams, or settings
that do not work as described.

Please attach the relevant section of `logs/latest.log` and include:

- Minecraft, Fabric Loader, MipMapPlus, and Sodium versions
- Selected mipmap level and texture-filtering setting
- Resource-pack name and resolution
- GPU model, VRAM, and maximum texture size when known
- Whether the problem remains with only Fabric Loader and MipMapPlus installed

Remove account tokens, server addresses, chat, and other private information
before uploading logs.

## Ideas and questions

Use
[GitHub Discussions](https://github.com/arogorn993-hue/MipMapPlus/discussions)
for setup questions, screenshots, compatibility experiences, and ideas that are
not yet concrete bug reports.

Use the
[feature request form](https://github.com/arogorn993-hue/MipMapPlus/issues/new?template=feature-request.yml)
when a proposal is specific enough to track as implementation work.

## Security

Do not post a security concern publicly. Follow the private reporting guidance
in [SECURITY.md](SECURITY.md).
